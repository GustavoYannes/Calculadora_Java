# Calculadora_Java
## Descrição
Este projeto consiste em uma calculadora desenvolvida em Java que realiza operações matemáticas básicas a partir de uma expressão digitada pelo usuário.
O programa é capaz de interpretar a entrada, identificar a operação e exibir o resultado correspondente.

---

## Funcionalidades

- Soma (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)
- Leitura de expressão digitada pelo usuário (ex: 2 + 3)
- Identificação automática da operação
- Exibição do resultado
- Tratamento de erros (como divisão por zero e entradas inválidas)

---

## Tecnologias utilizadas

- Java
- Programação orientada a objetos (POO)
- Manipulação de Strings
